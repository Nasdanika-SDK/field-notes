== About this note

This note is one of the Nasdanika Field Notes: short articles about the technologies and services
Nasdanika is built and published with, each one verified by a test where it can be. Every listing of
code in a note is included from its tests, every file shown was written by them when this edition
was built, and the versions it was tested with are measured by the tests, not declared. A recipe
says which of its steps the build checks and which are done by hand.

Edition {revnumber}, built on {revdate}, with the third-party versions of the Nasdanika SDK Runtime
{runtime-version}. The source of this note and its tests are at {fieldnotes-repo}, in
